# SFX Studio (SFXStudio)

SFX Studio is a standalone, cross-platform audio synthesis application built in C# using Avalonia UI. It is designed to run natively on Linux, Windows, and macOS. The tool allows developers and sound designers to programmatically generate custom sound effects using Digital Signal Processing (DSP) mathematical equations, frequency modulation, and time-based effects filters. 

Because every sound wave is calculated and synthesized from scratch by the application backend, 100 percent of the exported audio assets belong entirely to the user for unrestricted commercial use.

## Features

- Real-Time Cross-Platform Playback: Uses native operating system audio backends (aplay for Linux, PowerShell for Windows, and afplay for macOS) to preview sound adjustments instantly.
- Variable Oscillator Profiles: Supports four distinct mathematical wave shapes including Sine, Square, Sawtooth, and Triangle configurations.
- Frequency Modulation Matrix: Features adjustable base frequency, modulation speed, and modulation oscillation depth controls to create dynamic sci-fi textures.
- White Noise Explosion Engine: Incorporates a random noise generator paired with a digital Low-Pass Filter to synthesize heavy space rumbles, rocket thrusters, and explosion profiles.
- Integrated DSP FX Modules: Includes a time-based space echo delay loop and a modulated chorus/flanger feedback network.
- Macro Pattern Presets: One-click macro selectors for rapid generation of standard lasers, deep engine drones, and telemetry arrays alongside an automated chaos randomizer loop.
- Input Hotkeys: Pressing the spacebar triggers the active synthesis calculation loop immediately for swift sound testing.

## System Prerequisites

To compile and package this application from source, you must install the .NET SDK on your development machine.

- .NET SDK (Version 10.0 or newer)
- ImageMagick / Core Utilities (Required for icon conversion steps)

For real-time audio playback testing on Linux platforms, verify that the built-in advanced Linux sound architecture system tools (`aplay`) are installed on your distribution.

## Installation and Execution

1. Clone or download this project directory to your local drive.
2. Open a terminal panel inside the project root folder.
3. Execute the local development compiler command:

```bash
dotnet run
```

## Compilation and Deployment Packaging

To package the sound studio app into a single, standalone production file that bundles the full runtime framework, execute the command specific to your target operating system.

### Build for Linux Desktop (64-bit AMD/Intel)
```bash
dotnet publish -c Release -r linux-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfContained=true
```
The production executable file is exported to: `bin/Release/net10.0/linux-x64/publish/SFXStudio`

### Build for Microsoft Windows (64-bit AMD/Intel)
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfContained=true
```
The production executable file is exported to: `bin/Release/net10.0/win-x64/publish/SFXStudio.exe`

### Build for Apple macOS Silicon (M1/M2/M3/M4 Architecture)
```bash
dotnet publish -c Release -r osx-arm64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfContained=true
```
The production executable file is exported to: `bin/Release/net10.0/osx-arm64/publish/SFXStudio`

### Build for Apple macOS Legacy (64-bit Intel Architecture)
```bash
dotnet publish -c Release -r osx-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfContained=true
```
The production executable file is exported to: `bin/Release/net10.0/osx-x64/publish/SFXStudio`

*Note for macOS Deployments: If the operating system blocks initial binary execution, open a terminal folder near the target file and apply execution permissions with the command `chmod +x SFXStudio`.*
